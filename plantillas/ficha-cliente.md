# Ficha de cliente

Rellénala en la primera reunión y pégala como primer mensaje del proyecto
(o cópiala a `clientes/<empresa>/ficha.md`).

| Campo | Respuesta del cliente |
|---|---|
| Empresa | |
| Sector / nicho | |
| Nº de empleados y departamentos | |
| Herramientas actuales (CRM, ERP, email, WhatsApp…) | |
| Objetivo principal (vender más, ahorrar tiempo, escalar…) | |
| 3 tareas que más tiempo les quitan | |
| Canales de venta y captación | |
| Datos sensibles que manejan | |
| Presupuesto mensual orientativo (€) | |
| Plazo deseado | |
| Persona responsable en la empresa | |

## Correspondencia con las variables del prompt

| Variable | Campo(s) de la ficha |
|---|---|
| `{{EMPRESA}}` | Empresa |
| `{{SECTOR}}` | Sector / nicho |
| `{{EMPLEADOS_Y_DEPARTAMENTOS}}` | Nº de empleados y departamentos |
| `{{HERRAMIENTAS}}` | Herramientas actuales |
| `{{OBJETIVO}}` | Objetivo principal |
| `{{PROBLEMAS}}` | 3 tareas que más tiempo les quitan |
| `{{PRESUPUESTO_Y_PLAZO}}` | Presupuesto mensual + Plazo deseado |
