# Peticiones para probarlo

1. **Diagnóstico:** "Con la ficha de cliente, haz el diagnóstico completo por
   departamento y dame la tabla priorizada de oportunidades."
2. **Demo visual:** "Prepara la demo para una clínica dental de 12 empleados:
   antes/después, mapa del cerebro de IA, conversación de WhatsApp con un
   paciente y calculadora de ahorro."
3. **Tarjetas por nicho:** "Crea 6 tarjetas problema → solución → resultado
   para inmobiliarias, listas para Instagram."
4. **Construcción:** "Diseña el asistente de WhatsApp para cualificar leads de
   esta empresa: ficha, diagrama Mermaid, prompt del agente y montaje en n8n
   paso a paso."
5. **Propuesta:** "Convierte el diagnóstico en una propuesta comercial de 3
   fases con plazos, entregables y KPIs."
6. **Guion de venta:** "Dame el guion de demo de 5 minutos para presentar
   Nyland al gerente de un restaurante con 3 locales."
