# Clientes

Una carpeta por cliente: `clientes/<empresa>/`.

```
clientes/<empresa>/
├── ficha.md          # copia rellenada de plantillas/ficha-cliente.md
├── documentos/       # organigrama, procesos, catálogo, manuales, FAQ
├── diagnostico.md    # Fase 1 · IMAGINA
├── soluciones/       # Fase 2 · CONSTRUYE (una subcarpeta por solución)
├── demo/             # módulo de demostración visual (HTML, tarjetas, guion)
└── seguimiento.md    # Fase 3 · CRECE (KPIs y revisiones mensuales)
```

No subas datos personales de clientes finales ni credenciales al repositorio (RGPD).
